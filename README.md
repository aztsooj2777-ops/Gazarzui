# Газарзүй — нээлттэй сургалтын платформ

Ц. Азцоож багшийн газарзүйн хичээлийн Google Sites хуудсыг орлох, орчин үеийн
интерактив вэб платформ. **GitHub → Vercel → Supabase** гурвалаар ажиллана.

---

## Юу байгаа вэ?

| Хэсэг | Тайлбар |
|---|---|
| **Нүүр** (`index.html`) | Hero, өдөр бүр шинэчлэгддэг «Газарзүйн талаар юу мэдэх вэ?» 5 асуулт, баримт эргүүлэгч |
| **Хичээл** (`lessons.html`, `lesson.html`) | 22 бүтэн хичээл: 7, 8, 9-р анги + Геологийн хөгжлийн түүх. Агуулгын жагсаалт, нэр томьёо, бататгах дасгал |
| **Сорил** (`quiz.html`) | 95 асуулт, 6 ангилал, 3 түвшин, **ЭЕШ горим** (45 сек/асуулт), алдааны тайлбар |
| **Тоглоом** (`games.html`) | 6 тоглоом — доор дэлгэрэнгүй |
| **AI багш** (`chat.html`) | 30+ сэдвийн бэлтгэсэн хариулт + сонголтоор жинхэнэ Claude загвар |
| **Хэлэлцүүлэг** (`community.html`) | Сэдэв нээх, сэтгэгдэл, таалагдсан |
| **Тэргүүлэгчид** (`leaderboard.html`) | Сорил, тоглоом тус бүрээр шүүх |
| **Профайл** (`profile.html`) | Ахиц, оноо, 10 тэмдэг (badge), түүх |
| **Хэрэглэгдэхүүн** (`resources.html`) | Түргэн лавлах хүснэгт, томьёо, материалын сан |
| **Бидний тухай** (`about.html`) | Багшийн танилцуулга, санал хүсэлтийн маягт |

### Тоглоомууд

1. **Аймаг таних** — 21 аймаг + Улаанбаатарыг **жинхэнэ солбицлоор** байрлуулсан
   Монголын схем зураг дээр олох. Аймаг бүрд сонирхолтой баримт гарна.
2. **Далбаа таних** — 62 улсын далбаа → нэр
3. **Нийслэл таних** — улс ↔ нийслэл, хоёр чиглэлд
4. **Газарзүйн үг** — Wordle маягийн, монгол кирилл гарын хуваарьтай, 32 нэр томьёо
5. **Нэр томьёо тааруулах** — 30 хос ойлголт/тодорхойлолт, цагтай
6. **Аль нь их вэ?** — уулын өндөр, улсын талбай, голын урт, хүн ам, нуурын гүн

## Технологи

- **Frontend** — цэвэр HTML + CSS + JavaScript. **Build хийх шаардлагагүй**, `node_modules` шаардахгүй.
  Хуудсуудыг шууд браузераар нээж болно.
- **Supabase** — нэвтрэлт (Auth), хэрэглэгчийн профайл, оноо, хэлэлцүүлэг, санал хүсэлт.
- **Vercel** — статик хостинг + `/api/chat` serverless функц.
- **Anthropic Claude API** — AI багшийн хариулт (заавал биш).

> **Чухал:** Supabase болон AI-г холбоогүй байсан ч сайт **бүрэн ажиллана**.
> Тэр үед өгөгдөл нь тухайн төхөөрөмжийн `localStorage`-д хадгалагдаж,
> AI багш нь суурилагдсан мэдлэгийн сангаар хариулна. Энэ нь «Оффлайн горим» юм.

## 1. GitHub дээр байршуулах

```bash
cd website
git init
git add .
git commit -m "Газарзүйн сургалтын платформ"
git branch -M main
git remote add origin https://github.com/<таны-нэр>/<repo-нэр>.git
git push -u origin main
```

---

## 2. Vercel дээр нийтлэх

1. [vercel.com](https://vercel.com) → **Add New… → Project**
2. GitHub repo-гоо сонго.
3. Тохиргоо: **Framework Preset = Other**. Build command, Output directory-г хоосон орхи
   (`vercel.json` дотор аль хэдийн бичсэн).
4. **Deploy** дар.

Хэдхэн секундын дараа `https://<төслийн-нэр>.vercel.app` хаяг дээр сайт гарна.
Дараа нь `git push` хийх бүрд автоматаар шинэчлэгдэнэ.

---

## 3. Supabase холбох (нийтийн өгөгдөл)

Энэ алхмыг хийвэл оноо, хэлэлцүүлэг, профайл нь **бүх сурагчид хуваалцах** болно.

1. [supabase.com](https://supabase.com) → шинэ **Project** үүсгэ (үнэгүй багц хангалттай).
2. Зүүн талын **SQL Editor** → **New query** → энэ репод байгаа
   [`supabase/schema.sql`](supabase/schema.sql) файлыг **бүтнээр нь** хуулж наагаад **Run**.
   Энэ нь хүснэгтүүд, RLS дүрэм, триггер, эхлэлийн өгөгдлийг үүсгэнэ.
3. **Project Settings → API keys** хэсгээс дараах хоёрыг хуулж ав:
   - `Project URL`
   - `Publishable key` (`sb_publishable_...`) — эсвэл хуучин төсөлд `anon public`
4. [`assets/js/config.js`](assets/js/config.js) файлыг нээж бөглө:

```js
window.GZ_CONFIG = {
  SUPABASE_URL: "https://xxxxxxxxxxxx.supabase.co",   // /rest/v1/ БИЧИХГҮЙ
  SUPABASE_KEY: "sb_publishable_...",
  ...
};
```

5. Хадгалаад `git push`. Vercel автоматаар шинэчилнэ.

> ### ⚠️ Түлхүүрийн аюулгүй байдал
>
> | Түлхүүр | Хаана бичих вэ | Тайлбар |
> |---|---|---|
> | `sb_publishable_...` (эсвэл `anon`) | ✅ `assets/js/config.js` | Ил тавигддаг, нууц биш. RLS дүрэм хамгаална. |
> | `sb_secret_...` (эсвэл `service_role`) | ❌ **ХЭЗЭЭ Ч биш** | RLS-ийг бүрэн тойрдог админ эрх. Кодод оруулбал хэн ч бүх өгөгдлийг унших/устгах боломжтой болно. Зөвхөн сервер талын env хувьсагчид байрлана. |
>
> Санамсаргүй ил болсон secret түлхүүрийг Supabase Dashboard → API keys дээрээс
> нэн даруй **rotate** хийнэ.

### Нэвтрэлтийн тохиргоо (санал болгох)

**Authentication → Providers → Email**:
- Сургуулийн орчинд хурдан ажиллуулахыг хүсвэл *Confirm email*-ийг **унтраах**
  (сурагчид и-мэйлээ баталгаажуулах шаардлагагүй болно).
- **Authentication → URL Configuration → Site URL** дээр Vercel хаягаа оруул.

## 4. AI багшийг жинхэнэ загвартай холбох (заавал биш)

Холбоогүй үед AI багш нь `assets/js/data/kb.js` доторх **30+ бэлтгэсэн хариулт**-аар
ажиллана — энэ нь ихэнх түгээмэл асуултыг бүрэн хангадаг.

Илүү чөлөөт ярианы хариулт хүсвэл:

1. [console.anthropic.com](https://console.anthropic.com) дээр API түлхүүр үүсгэ.
2. Vercel → төслийн **Settings → Environment Variables**:

   | Нэр | Утга |
   |---|---|
   | `ANTHROPIC_API_KEY` | `sk-ant-...` |
   | `CHAT_MODEL` | *(заавал биш)* өөр загвар ашиглах бол, ж нь `claude-sonnet-5` |

3. **Redeploy** дар.

`api/chat.js` функц нь Anthropic Messages API руу хандаж, сурагчид зориулсан
монгол хэлний богино, тодорхой хариулт буцаана. Хариулт бүрд мэдлэгийн сангаас
олдсон хамгийн ойрын материалыг лавлах болгон дамжуулдаг тул багшийн агуулгад
тулгуурласан хариулт өгнө.

Түлхүүр тохируулаагүй бол функц `503` буцаах ба вэб тал **автоматаар**
мэдлэгийн сан руу шилжинэ — хэрэглэгч алдаа хардаггүй.

## Агуулгыг өөрчлөх

Бүх агуулга энгийн JS файлд байгаа тул програмчлалын мэдлэггүйгээр засаж болно.

| Юу засах вэ | Файл |
|---|---|
| Сайтын нэр, багшийн мэдээлэл, и-мэйл | `assets/js/config.js` |
| 7, 8-р ангийн хичээл | `assets/js/data/lessons-a.js` |
| 9-р анги, геологи | `assets/js/data/lessons-b.js` |
| Сорилын асуултууд | `assets/js/data/quizbank.js` |
| AI багшийн хариултууд | `assets/js/data/kb.js` |
| Аймаг, улс, тоглоомын өгөгдөл, баримтууд | `assets/js/data/geodata.js` |
| Өнгө, фонт, дизайн | `assets/css/theme.css` |

### Шинэ хичээл нэмэх жишээ

`assets/js/data/lessons-b.js` дотор массивын төгсгөлд нэмнэ:

```js
{
  id: "g9-06", grade: 9, track: "9-р анги", emoji: "🌐", minutes: 12,
  title: "Хичээлийн нэр",
  summary: "Нэг өгүүлбэрийн товч тайлбар.",
  tags: ["Шошго"],
  objectives: ["Зорилт 1", "Зорилт 2"],
  sections: [
    { h: "Бүлгийн гарчиг", p: ["Догол мөр…"], list: ["Жагсаалтын мөр"] }
  ],
  terms: [{ t: "Нэр томьёо", d: "Тайлбар" }],
  quiz: [
    { q: "Асуулт?", options: ["А","Б","В","Г"], answer: 0, why: "Яагаад гэвэл…" }
  ],
},
```

### Шинэ сорилын асуулт нэмэх

`assets/js/data/quizbank.js`:

```js
{ cat:"Монголын газарзүй", lvl:2, q:"Асуулт?",
  options:["А","Б","В","Г"], answer:1, why:"Тайлбар." },
```

`lvl`: 1 = хялбар, 2 = дунд, 3 = хүнд.

## Локал компьютер дээр турших

Build хэрэггүй — гэхдээ энгийн вэб сервер ашиглах нь зөв (`file://` дээр зарим
зүйл хязгаарлагдана).

```bash
npx serve .
```

эсвэл Python суулгасан бол:

```bash
python -m http.server 8123
```

Дараа нь `http://localhost:8123` руу ор.

## Хандалт ба хүртээмж

- Гэрэл / харанхуй горим (систем тохиргоог дагана, гараар солино)
- Гар (keyboard) навигац, `:focus-visible` тодруулга
- Сорилд `1–4` товчоор хариулт сонгох
- `prefers-reduced-motion` дэмждэг
- Гар утас, таблет, дэлгэц бүрд дасан зохицсон
