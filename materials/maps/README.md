# Газарзүйн зураг

Энэ фолдерт **газрын зураг, атлас, зургийн даалгавар**-ын файлуудаа хийнэ.
Дэмжигдэх төрөл: `.pdf`, `.png`, `.jpg`, `.docx`, `.pptx`

## Хэрхэн нэмэх вэ

**1-р алхам.** Файлаа энэ фолдерт хуулна.

> ⚠️ Файлын нэрэнд **кирилл үсэг, хоосон зай хэрэглэхгүй** — вэб хаягт асуудал үүсгэдэг.
> Буруу: `Монгол орны бүс.png` · Зөв: `mongol-bus.png`

**2-р алхам.** [`assets/js/data/materials.js`](../../assets/js/data/materials.js) файлыг нээж,
`id: "maps"` гэсэн бүлгийн `items` жагсаалтад нэг мөр нэмнэ:

```js
{ t: "Монгол орны байгалийн бүсийн зураг", f: "materials/maps/mongol-bus.png", size: "1.2 MB" },
```

- `t` — сайт дээр харагдах нэр (кирилл байж болно)
- `f` — файлын зам
- `size` — файлын хэмжээ (заавал биш ч харагдац сайжирна)

**3-р алхам.** `git add -A && git commit -m "Газрын зураг нэмэв" && git push`

Vercel автоматаар шинэчилж, [materials.html#maps](../../materials.html) хаяг дээр гарна.
